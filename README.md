# Zak Breakout

A neon arcade brick-breaker: 15 levels, 3 bosses, 9 power-ups, combos and a glimmering ZAK.

**Play:** https://blixenzach.github.io/zak-breakout/

On a phone, open the link and add it to your home screen (the game's INSTALL APP button shows how).
It then opens fullscreen like an app and plays offline.

Made with plain HTML, CSS and JavaScript. No libraries, no ads.
